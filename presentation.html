📐 04 // 3D Architecture Diagram

Схема сквозной работы системы.

3D-слои показывают, как зрительный сигнал камеры обрабатывается в Gemini 2.5 Flash, проверяется по шине безопасности и передается в байты Bluetooth LWP3.

Слой архитектуры Технология Параметры Роль в OmniBrick
1. Сенсорный шлем Камера телефона + Микрофон 4K Vision, 1 FPS Worker Фоновое сканирование препятствий без задержки речи
2. Когнитивное ядро Google Gemini 2.5 Flash + Память < 240 мс отклик речи Генерация команд, характер, юмор, привычки пилота
3. Шина инструментов MCP (Model Context Protocol) Typed JSON Schema Безопасный вызов моторов, калибровка ламината
4. Аппаратный драйвер LEGO Wireless Protocol v3 (LWP3) UUID 0x1623, 20Hz Прямая передача байткода на хаб 51515 без взлома
5. Монетизация RevenueCat Purchases SDK omnibrick_pro ($9.99/mo) Подписки, валюта 🧱 Bricks, 70% роялти создателям
