Робототехника застряла в
2010 году. Мы это меняем.

Миллионы школьников и мейкеров по всему миру собирают LEGO Mindstorms 51515 и SPIKE Prime, но программно роботы остаются слепыми и глухими калькуляторами.

❌ Как у всех (Старый подход)

  • • Слепые роботы: Примитивные датчики цвета/линий, ноль пространственного зрения.
  • • Примитивный Scratch: Однообразные блоки «крути мотор 2 секунды» без рассуждений.
  • • Дороговизна: Платы с ИИ (Raspberry Pi 5 + Coral TPU) стоят более $200–$300.
  • • Изолированность: Нет экосистемы, нет магазина чертежей и связи с миром.

✅ OmniBrick (Новый подход)

  • • Старый смартфон на роботе: Камера видит объекты, распознает препятствия в 3D.
  • • Голос и эмоции: Робот строит глазки на экране телефона и говорит вслух без задержек.
  • • $0 на контроллер: Прямое подключение по Web Bluetooth LWP3 без перепрошивки LEGO-хаба!
  • • Самообучение: Робот запоминает привычки пилота (Antigravity IDE, калибровка пола).
🏗️ 5-Уровневая модульная архитектура

Сквозной пайплайн:
От взгляда камеры до шестерёнок

OmniBrick построен по стандартам промышленной робототехники: строгое разделение интерфейса, когнитивного ядра ИИ, шины памяти и аппаратной абстракции HAL.

L1
Mobile Touch Cockpit: React 19 + Tailwind v4 (60 FPS, нативный Capacitor)
L2
State & Monetization: RevenueCat Purchases SDK (Entitlements, Bricks)
L3
Cognitive Core & Memory: Асинхронное зрение + Память привычек пилота
L4
MCP Protocol: Model Context Protocol (вызов инструментов drive, turn, speak)
L5
Robotics HAL: LEGO LWP3 Bluetooth (UUID 1623) & 20Hz симулятор

⚡ Решение задержки: Dual-Core Async

Мы устранили 2-секундный лаг классических VLM-моделей:

[1. Vision Core (1 FPS)] Фоновое сканирование пространства ➔ обновление World Cache.
[2. Fast Voice (<250ms)] Мгновенный ответ голосом с использованием уже готового кеша зрительного мира!
